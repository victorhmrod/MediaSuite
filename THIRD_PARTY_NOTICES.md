# Third-party notices

## Media Suite

The unified native application incorporates LocalFlix (AGPL-3.0) and
MagnifyFactory (GPL-3.0). Their source code and licences are preserved under
`suite/vendor/`. The combined application is distributed under AGPL-3.0.
The native UI dynamically links Qt Widgets, Network, Concurrent, Sql, Svg,
OpenGL and OpenGLWidgets; playback uses libmpv from the LocalFlix dependency
distribution. SQLite is provided by Qt's SQLite plugin. See the dependency
notices below and the LocalFlix upstream distribution for its libmpv build.

The Media Suite package includes FFmpeg/FFprobe when available at build time;
`LICENSE-FFmpeg.txt` preserves the tool distribution's licence. The download
worker bundles Python, yt-dlp and its default dependencies with PyInstaller.
Node.js/Deno and the external document/archive/PDF/3D tools are not bundled.
