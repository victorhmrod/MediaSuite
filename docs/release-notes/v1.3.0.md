# Media Suite 1.3.0

## Conversion on the download page

- Select the output format before downloading. The integrated converter starts
  automatically after the source file has downloaded.
- Convert to supported video, audio, or first-frame image formats. The list comes
  from the application's format registry.
- Track conversion progress and errors on the download card, cancel, retry
  conversion without another download, or choose a new output format afterward.
- Playlist downloads pass each downloaded file to the shared converter queue.
- Preserve original downloads and existing output files. Successful video outputs
  can be imported into the library automatically.
- Use container-compatible codecs for WebM, AVI, WMV, and FLV outputs.

## Private GitHub update discovery

- Configure a read-only token in **Settings → Application updates**. Tokens are
  stored in Windows Credential Manager.
- Check stable releases manually or automatically at startup and receive an
  update notification.
- Download the private release installer and verify its size and SHA-256 digest.
  Tokens are not forwarded to the signed download CDN URL.
- Install only on request, after active jobs finish. The installer path and
  per-user/all-user installation mode are retained for recognized installations.
- Install this version once to enable discovery for future releases.
