# Media Suite 1.4.2

## Updates without a token

- **Check for updates** now works out of the box. No GitHub token is required to
  discover and download new releases from the public repository.
- Saving a token in **Settings → Application updates** is optional and only needed
  if the repository becomes private. A saved token is still stored in Windows
  Credential Manager and sent only to the GitHub API host, never to the signed
  download CDN URL.
- Downloads are still verified against the release's size and SHA-256 digest
  before installation.

## Downloads

- `MediaSuite-1.4.2-setup.exe`: Windows x64 installer.
- `MediaSuite-1.4.2-win64.zip`: portable application.
- `SHA256SUMS.txt`: SHA-256 checksums.
