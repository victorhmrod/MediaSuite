First release of **YT Downloader**: a Windows desktop app for downloading YouTube videos and audio. It is built on
yt-dlp and uses the LocalFlix look.

### Features
- Paste a link and see a preview first: thumbnail, title, channel, length and views.
- Download **MP4 video** at the best quality available or a chosen resolution (only the resolutions that video
  actually has are listed), or **MP3 audio** at 192 kbps.
- Download **whole playlists** into their own folder, with numbered files.
- A **downloads list** with progress, speed and time left. Up to 3 downloads run at a time, and each one has
  cancel, retry, *open file* and *show in folder*.
- Your default folder, format and quality are remembered. The *Settings* page shows which
  components were found: yt-dlp, FFmpeg and a JavaScript runtime.
- Interface in Brazilian Portuguese. Installer in English and Brazilian Portuguese.

### Downloads
| File | What it is |
|------|------------|
| `YTDownloader-1.0.0-setup.exe` | **Recommended.** Installs per user with no admin rights, adds a Start Menu entry, and can be uninstalled from *Settings → Apps* |
| `YTDownloader-1.0.0-portable.exe` | Single file, no installation. Starts a little slower |
| `SHA256SUMS.txt` | Checksums for verifying the downloads |

### Requirements
- Windows 10/11 x64.
- Recommended: [FFmpeg](https://ffmpeg.org/) (`winget install Gyan.FFmpeg`) for MP3 conversion and for video
  above 720p.
- Recommended: [Node.js](https://nodejs.org/) (`winget install OpenJS.NodeJS.LTS`) or Deno, which yt-dlp needs to
  unlock every YouTube format.

### Notes
- Bundles yt-dlp 2026.10.21.
- The executables are not code-signed, so SmartScreen may warn you. Choose *More info → Run anyway*.
- Only download content you have the right to download.
