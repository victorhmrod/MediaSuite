# Media Suite 1.2.1

- New flat application icon: a white clapperboard on a solid black background.
- The icon is embedded in the Windows executable and used by the application,
  taskbar, shortcuts, installer, and uninstall entry.
- Includes the editable SVG and a generator for PNG and multi-resolution ICO
  assets, including small Windows icon sizes.
