# Media Suite 1.4.0

## A geometric new interface

- Rectangular buttons with opposing upper-right and lower-left chamfers across
  the library, downloader, converter, settings, and dialogs.
- Short, interruptible hover, focus, and press transitions, including keyboard
  interaction, with a visible focus outline and distinct disabled states.
- Graphite surfaces, ice-blue accents, clearer typography, and a reorganized
  sidebar with library and tool sections.
- Angular media posters, flat input fields, and consistent menus and panels.
- Native Windows window corners match the new geometric design where supported.

Download, conversion, playback, and private GitHub update discovery continue to
use the existing integrated engines. Tokens remain in Windows Credential Manager.
