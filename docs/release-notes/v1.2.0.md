# Media Suite 1.2.0

Media Suite combines downloads, an offline library and player, conversion, and
editing in a single Windows application with the LocalFlix dark theme.

## Changes

- English interface throughout navigation, download previews, progress messages,
  errors, library screens, and conversion tools.
- English repository documentation and build output, including the retained
  standalone downloader.
- New Windows installer with per-user installation by default, Start Menu and
  optional desktop shortcuts, and Windows Settings uninstall support.
- Multi-source downloads through yt-dlp: YouTube, Google Drive, supported websites,
  direct media files, embedded videos, and non-DRM HLS/DASH streams.
- Optional cookies-file authentication, playlist handling, and automatic library
  import remain available.

## Downloads

| File | Purpose |
| --- | --- |
| `MediaSuite-1.2.0-setup.exe` | Windows x64 installer |
| `MediaSuite-1.2.0-win64.zip` | Portable application; extract and run `MediaSuite.exe` |
| `SHA256SUMS.txt` | SHA-256 checksums of the installer and portable ZIP |

Python, Qt, FFmpeg, FFprobe, and libmpv are bundled. Some websites require Node.js
or Deno on PATH. Advanced PDF, document, archive, and 3D tools may require their
external dependencies. Website support depends on the extractor and permissions.

The library remains in `%APPDATA%\MediaSuite`. Uninstalling preserves library
data, preferences, and downloaded media.

## Validation

The release is checked with the native regression suites, download worker tests,
English UI screenshots, and a silent install/startup/uninstall smoke test.
