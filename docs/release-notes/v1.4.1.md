# Media Suite 1.4.1

- Fixed the sidebar highlighting **Home** as selected after opening another page.
  The first navigation button received keyboard focus at startup and kept its focus
  outline and hover glow while a different page was active.
- Focus outlines and the focus glow now appear only for keyboard navigation (Tab,
  Shift+Tab, or a shortcut), never after window activation or a mouse click.
- Only the page you are actually on is shown as selected.

- `MediaSuite-1.4.1-setup.exe`: Windows x64 installer.
- `MediaSuite-1.4.1-win64.zip`: portable application.
